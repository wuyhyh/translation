## 27.6 走向市场

在开始销售 USB 设备之前，根据您希望或需要获得的合规级别，有几个必要的步骤。

首先，有一些强制性的步骤需要执行。其中最相关（也是最昂贵）的一步是获取官方的供应商 ID (Vendor ID, VID)。VID 是一个唯一的标识符，每家公司都从 USB 实施者论坛 (USB Implementers Forum) 获得。获取 VID 有三种选择：

³⁷https://github.com/hathach/tinyusb

<!-- page: 870 -->

- 成为 USB-IF 会员并支付年度会费。在撰写本章时，会费为每年 5000 美元。会员资格具有多项好处。其中最重要的包括：
  - 免费获得一个供应商 ID（如果之前未分配过）
  - 有资格参加 USB-IF 赞助的免费季度合规研讨会
  - 有机会参与 USB-IF 的营销计划和活动，例如零售通讯、商店端架、精选产品等
  - 在 USB 关键联系人列表中列出公司信息
  - 有资格被列入 usb.org 网站上的 USB 当前产品列表以及定期发布的 USB-IF 零售通讯中
  - 加入 USB-IF 标志计划时免除标志管理费
  - 在开发者大会、电子商店产品等方面享受折扣
  - 有资格参与设备工作组
- 以 6000 美元的一次性费用从 USB-IF 购买供应商 ID。但请注意，仅仅购买 VID 并不授权您在产品上使用 USB 标志。为了做到这一点，您需要成为 USB-IF 非会员标志被许可人。此许可费为两年期限 3500 美元。此外，请注意，此许可费并不赋予您其他 USB-IF 会员权益，例如合规研讨会。
- 从 MCS Electronics³⁸ 购买个人 PID。嗯，这看起来更像是一种意大利式³⁹的绕过障碍的方式，但 MCS Electronics 是一家荷兰公司，多年前收购了一个 VID，并开始从他们庞大的资源池中出售个人 PID。他们与 USB-IF 有过纠纷，但根据荷兰法律，他们似乎可以这样做，而 USB-IF 也停止了与他们的对抗。因此，如果您需要 USB 标志合规性（下一节将详细介绍），则需要购买自己的 VID 并投资约 10,000 美元。相反，如果您只需要一个唯一的 VID/PID 对，那么以低于 20 美元的价格从 MCS 购买个人 PID 是可以的（是的，你没看错）。

下一个强制性步骤是至少进行欧洲 CE 和美国 FCC 的合规测试。凭借这两个认证，您可以在地球上大多数国家销售您的设备。在选择测试实验室时，您有两个主要选择：

- 使用更昂贵但离您更近的测试实验室。
- 使用位于中国但便宜得多的测试实验室。

请注意，您可以在中国以低于 500 美元的价格获得 CE/FCC 认证。在中国，有几家被通知用于监管测试的公司，在许多情况下工作迅速且高效。我亲自访问了深圳的几个相关测试实验室，我可以保证，您可以找到与几家“知名”西方公司提供的相同质量和专业水平。在测试您的设备时，我建议至少执行以下测试：

³⁸https://bit.ly/34sPTic ³⁹由于作者是意大利公民，他完全有资格这样说 :-D

<!-- page: 871 -->

- 电磁兼容性 (EMC) 指令 2014/30/EU⁴⁰ 的测试。
- FCC 第 47 篇 CFR 第 15 部分⁴¹ 的测试。
- 低电压指令 (LVD) (2014/35/EU)⁴² 的测试。
- REACH-SVCH⁴³ 的测试。

所有这些测试在中国测试实验室的费用将低于 1000 美元。如果您打算设计 5V USB 设备，则 LVD 测试不是强制性的。然而，获得此认证以及 REACH-SVCH 认证，将在全球范围内运输您的设备时为您省去很多麻烦：海关人员可以将每一笔愉快的交易变成一场噩梦。请相信这位作者。

现在还有几个额外的可选认证您可能需要。如果您希望/需要获得 USB 标志合规性⁴⁴（见图 24），则需要遵循专门的路径。为了确保基于 USB 的设备（主机、设备、集线器等）之间的互操作性，USB-IF 严格规定您的设备遵循标准的方式。因此，您不能随意在设备上使用任何 USB 标志。相反，您必须接受由 USB-IF 管理的一系列合规测试。这些合规测试将确保被测设备符合 USB 规范的相关部分。通过后，产品将获得使用相关 USB-Certified® 标志的能力，此外，产品将被列入 USB 集成商列表，这只是一个由 USB-IF 维护的列表，包含已满足强制合规标准的 USB 产品列表。在获得 USB 合规认证的路径上，必须完成两个组成部分：检查表和合规测试。有关更多信息，请参阅 USB-IF 网站上的专门页面⁴⁵。在遵循此路径时，请注意这将花费您至少 10,000 美元，并强烈建议接受专业顾问的支持。

最后，您可能需要为您的设备和驱动程序获取 Windows 硬件质量实验室 (WHQL) 认证。嗯，这不是一个简单的步骤。微软提供了一个专门的认证计划⁴⁶，以及一套专门用于执行“预合规”测试的工具⁴⁷。同样，我的建议是向经验丰富的测试实验室寻求帮助。请准备好投入大量资金。
