## 1.2 STM32 微控制器简介

STM32 是一个广泛的微控制器（microcontroller）系列，分为十七个子系列，每个子系列都有其独特的特性。ST 于 2007 年开始该系列的市场生产，从 STM32F1 系列开始，该系列目前仍在生产中。图 1.12 展示了 STM32F103 MCU 的内部芯片裸片（die），这是最广泛使用的 STM32 MCU 之一¹²。所有 STM32 微控制器都具有一个 Cortex-M 内核（core），以及一些独特的 ST 特性（如 ARTTM 加速器）。内部而言，每个微控制器由处理器内核、静态 RAM、闪存存储器、调试接口以及各种其他外设组成。一些 MCU 提供额外的内存类型（EEPROM、CCM 等），并且针对低功耗应用的整个设备产品线也在不断增长。

### 1.2.1 STM32 产品组合的优势……

STM32 平台为嵌入式开发人员提供了多项优势。本段试图总结其中相关的主要优势。

- 它们是基于 Cortex-M 的 MCU：对于刚接触该平台的人来说，这一点可能还不是很清楚。作为基于 Cortex-M 的微控制器，这确保了市场上有多种工具可用于开发您的应用程序。ARM 已成为嵌入式世界的一种标准（这在 Cortex-A 处理器中尤为真实；在 Cortex-M 市场细分中，仍有几个优秀的替代方案：PIC、MSP430 等），并且到 2020 年已售出 1600 亿台设备，这有力地证明了投资该平台是一个不错的选择。
- 免费的基于 ARM 的工具链：得益于基于 ARM 的处理器普及，可以使用完全免费的工具链进行工作，无需投入大量资金即可开始使用该平台，这对于爱好者或学生来说极其重要。
- 知识复用：STM32 是一个相当庞大的产品组合，基于一个共同点：其主要 CPU 平台。这确保了，例如，在

- 针对特定 STM32Fx CPU 工作时获得的知识可以轻松地应用于同一系列的其他设备。此外，使用 Cortex-M 处理器允许您在（或您的采购团队）决定切换到其他供应商的 Cortex-M MCU 时（理论上）复用大部分已获得的技能。
