# 1. STM32 微控制器（microcontroller）产品组合简介

本章对 STM32 整个产品组合进行简要介绍。其目的是向读者介绍这个相当复杂的微控制器家族，该家族细分为十七个不同的子系列。这些子系列共享一组共同特性，同时各自具备特定系列独有的功能。此外，本章还将对 Cortex-M 架构进行简要介绍。本章无意成为 Cortex-M 架构或 STM32 微控制器的完整参考手册，而是旨在为读者提供一份指南，帮助他们在超过 1200 款微控制器中选出最适合自身开发需求的那一款——毕竟，面对如此庞大的选择范围，要做出决定并不容易。

## 1.1 ARM 处理器简介

如今，"ARM"一词既指众多精简指令集计算（RISC）架构家族，也指多个完整的内核（core）家族。这些内核是许多芯片制造商所生产的 CPU 的基本构建模块（因此称为"核"）。在涉及 ARM 处理器时，由于存在许多不同的 ARM 架构修订版本（ARMv6、ARMv6-M、ARMv7-M、ARMv7-A、ARMv8-M 等）以及许多基于这些架构修订版本的核心架构，很容易产生混淆。为了便于理解，例如，基于 Cortex-M4 内核的处理器就是按照 ARMv7-M 架构设计的。

ARM 架构是一组规范，涵盖指令集、执行模型、内存组织与布局、指令周期等方面，精确描述了一台将实现该架构的机器。如果你的编译器能够为该架构生成汇编指令，那么它就能够为所有实现该架构的实际机器（即处理器）生成机器代码。

Cortex-M 是一组物理内核家族，设计用于与厂商特定的硅器件进一步集成，从而构成完整的微控制器。内核的工作方式不仅由其对应的 ARM 架构（如 ARMv7-M）定义，还由芯片制造商所集成的外设和硬件能力决定。例如，Cortex-M4 内核架构设计为支持在两个特定内存区域中使用一种称为位带（bit-banding）的特性进行位数据访问操作，但是否实际添加该特性取决于具体的实现方案。STM32F1 是基于 Cortex-M3 内核的微控制器系列，实现了该位带特性。图 1.1 清晰地展示了基于 Cortex-M3 的微控制器与其 Cortex-M3 内核之间的关系。

ARM Holdings 是一家英国公司，为日本软银（Softbank）控股集团的子公司，负责开发 ARM 产品的指令集和架构，但不制造器件。这是 ARM 世界的一个重要特点，也是众多芯片制造商能够基于 ARM 架构和内核开发、生产并销售微控制器的原因。ST 微电子（ST Microelectronics）就是其中之一，目前也是少数销售完整 Cortex-M 处理器产品组合的制造商之一。

ARM Holdings 既不制造也不销售基于自身设计的 CPU 器件，而是将处理器架构授权给相关方。ARM 提供多种授权条款，在费用和交付物方面各不相同。在提及 Cortex-M 内核时，也常使用知识产权（IP）核这一说法，指的是被视为某一方（即 ARM Holdings）知识产权的芯片设计版图。

得益于这种商业模式以及低功耗能力、某些架构的低生产成本等重要特性，ARM 在数量上是最广泛使用的指令集架构。基于 ARM 的产品已变得极为流行。截至 2020 年，已生产超过 1600 亿颗 ARM 处理器。基于 ARM 的处理器装备了全球约 95% 的移动设备。许多主流且广受欢迎的 64 位多核 CPU，用于已成为电子行业标志性的设备（如 Apple 的 iPhone），都是基于 ARM 内核的。近年来，Apple 发布了 Apple M1，这是一款基于 ARMv8.5-A 架构的 ARM 片上系统（system on chip）（SoC），由 Apple 自行设计，作为其 Macintosh 计算机和 iPad Pro 平板电脑的中央处理器（CPU）和图形处理器（GPU）。

作为一种广泛采用的标准，有大量编译器和工具，以及操作系统（operating system）（Linux 是 Cortex-A 处理器上最常用的操作系统）支持这些架构，为开发者提供了丰富的应用构建机会。

### 1.1.1 Cortex 和基于 Cortex-M 的处理器

ARM Cortex 是一组在嵌入式领域广受欢迎的 32/64 位架构和内核。Cortex 微控制器分为三个主要子系列：

- Cortex-A，其中 A 代表 Application（应用），是一系列为执行复杂计算任务的设备提供多种解决方案的处理器，例如承载丰富的操作系统（OS）平台（Linux 及其衍生系统 Android 最为常见），并支持多个软件应用。Cortex-A 内核装备了大多数移动设备（如手机和平板电脑）中的处理器。在这一市场细分中，我们可以找到多家芯片制造商，从销售目录产品的厂商（TI、Freescale 以及 STM 的 STM32MP1）到为其他被许可方生产处理器的厂商。在这一系列中最常见的内核中，有广受欢迎的 32 位 Cortex-A7 和 Cortex-A9 处理器（它们仍然常见于多款廉价单板计算机（SBC）上），以及最新的超高性能 64 位 Cortex-A77 和 Cortex-A78 内核。
- Cortex-M，其中 M 代表 eMbedded（嵌入式），是一系列可扩展、兼容、节能且易于使用的处理器，专为低成本嵌入式市场设计。Cortex-M 系列针对成本和功耗敏感的 MCU 进行了优化，适用于物联网、连接性、电机控制、智能计量、人机界面设备、汽车和工业控制系统、家用家电、消费电子产品和医疗器械等应用。在这一市场细分中，我们可以找到许多生产 Cortex-M 处理器的芯片制造商，ST Microelectronics 就是其中之一。
- Cortex-R，其中 R 代表 Real-Time（实时），是一系列为嵌入式系统提供高性能计算解决方案的处理器，在这些系统中，可靠性、高可用性、容错性、可维护性和确定性实时响应至关重要。Cortex-R 系列处理器提供快速且确定性的处理和高性能，同时满足苛刻的实时约束。它们将这些特性集成为性能、功耗和面积优化的封装，使其成为要求容错性的可靠系统中的可靠之选。

接下来的章节将介绍 Cortex-M 处理器的主要特性，尤其是从嵌入式开发者的角度来看。

#### 1.1.1.1 内核寄存器（register）

与所有 RISC 架构一样，Cortex-M 处理器是加载/存储（load/store）型机器，它们仅对 CPU 寄存器执行操作，¹ 但有两类指令除外：加载和存储指令，用于在 CPU 寄存器和内存位置之间传输数据。

¹这并不完全正确，因为 ARMv6/7 架构中还有其他可以访问内存位置的指令，但就本讨论而言，最好将该句视为正确。

图 1.2 展示了 Cortex-M 内核寄存器。其中一些寄存器仅在 M3、M4 和 M7 等更高性能系列中可用。R0-R12 是通用寄存器（general-purpose register），可作为 ARM 指令的操作数。然而，某些通用寄存器可被编译器用作具有特殊功能的寄存器。R13 是堆栈指针（stack pointer）（SP）寄存器，也被称为分组的（banked）寄存器。这意味着该寄存器的内容会根据当前 CPU 模式（特权模式或非特权模式）而变化。此功能通常被实时操作系统（real-time operating system）（RTOS）用于执行上下文切换（context switching）。
