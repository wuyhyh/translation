### 1.2.2 …及其缺点

本书不是宣传册，也不是由营销人员编写的文档。作者也不是 ST 的员工，或与 ST 有业务往来。因此，可以说该平台存在一些陷阱。

- 学习曲线：STM32 的学习曲线可能相当陡峭，尤其是对经验不足的用户而言。如果你完全新手于嵌入式开发，学习如何开发 STM32 应用的过程可能会令人沮丧。尽管 ST 在努力改善整体文档和官方库方面做得很好，但处理该平台仍然很困难，这很遗憾。历史上，ST 的文档对于经验不足的人来说并不是最好的，过于晦涩且缺乏清晰的示例。

¹³由于 2020 年代的硅片市场危机，这一口号不再有效。IC 行业的疯狂状况导致低成本 IC（受影响最大的部分）价格上涨超过 25%。然而，祸不单行，对于低成本应用，STM32F0 系列仍然是一个值得评估的系列，除非 8 位解决方案适合你。

<!-- page: 54 -->

- 文档碎片化且分散：ST 正在积极改进 STM32 平台的官方文档。你可以在 ST 网站上找到许多巨大的数据手册，但对于其 HAL 来说，仍然缺乏良好的文档。CubeHAL 的近期版本提供了一或多个“CHM”文件¹⁴，这些文件是从 CubeHAL 源代码中的文档自动生成的。然而，这些文件不足以开始使用该框架进行编程，尤其是如果你对 STM32 生态系统和 Cortex-M 世界是新手。
- 存在缺陷且性能不佳的 HAL：坦率地说，ST 的官方 HAL 多年来有了很大改进，但它仍在演变中，并且在 HAL 的高级和较少普及的模块中，发现一些严重缺陷是很常见的，就像作者在使用 HAL_PCD 模块时遇到的情况一样（我花了两个月时间识别出一个影响 STM32L052 MCU 上 USB HAL 库的棘手缺陷）。ST 正在积极修复 HAL 缺陷，但似乎距离“稳定版本”还很远。此外，他们的软件发布生命周期过于陈旧，不适合我们生活的时代：缺陷修复在几个月后发布，有时修复本身带来的问题比损坏的代码更多。最后，CubeHAL 远不能被认为是一个优化的库。HAL 被设计为从底层家族和特定 MCU 中抽象出来，这要求 HAL 例程充满 if-then-else 语句。对于时间关键型应用，ST 发布了 CubeHAL-LL 库，这本质上是一组宏，用于简化外设寄存器的操作。再次提醒，你是飞行员，你必须驾驭所有这些工具。

## 1.3 STM32 子系列概览

![Image from PDF page 54](../images/page-0054-image-01.png)

如果你是 STM32 世界的新手，并且已经拥有一个 STM32 开发套件或一个你迫不及待想要开始使用的定制设备，那么你可以安全地跳过这段长（且相当枯燥 :-) ）的文字，直接跳到下一段。

正如你所读到的，STM32 是一个相当复杂的产品系列，涵盖十七个产品子系列。图 1.13 总结了当前的 STM32 产品组合。图表将子系列聚合为四个宏观组：高性能、主流、超低功耗和无线 MCU。

高性能微控制器是那些专为 CPU 密集型和多媒体应用设计的 STM32 MCU。它们是基于 Cortex-M3/4F/7 的 MCU，最大时钟频率范围从 120MHz (F2) 到 550MHz (H7)。该组中的一些 MCU 提供 ARTTM 加速器，这是一种 ST 技术，允许从闪存内存中执行 0 等待。

¹⁴CHM 文件是一种典型的 Microsoft 文件格式，用于将 HTML 格式的文档分发在单个文件中。它在 Windows 操作系统上非常常见，你可以在 MacOS 和 Linux 上找到几个好的免费工具来阅读它们。

![Image from PDF page 55](../images/page-0055-image-01.jpeg)

图 1.13：STM32 产品组合

主流 MCU 是为成本敏感型应用开发的，其中 MCU 的成本必须低于 1 美元/件，且空间是一个强约束。在该组中，我们可以找到基于 Cortex-M0/0+/3/4 的 MCU，最大时钟频率范围从 48MHz (F0) 到超过 170MHz (G4)。

超低功耗组包含那些针对低功耗应用的 STM32 MCU 家族，用于需要降低总功耗以确保更长电池寿命的电池供电设备。在该组中，我们可以找到基于 Cortex-M0+ 的 MCU，用于成本敏感型应用，以及基于 Cortex-M4F 的微控制器，具有动态电压缩放 (DVS)，这是一种允许根据频率优化内部 CPU 电压的技术。此外，ST 最近在该类别中也引入了具有新 Cortex-M33 内核的 MCU，专为安全是强约束的应用设计。该组的 MCU 范围从 32MHz Cortex-M0+ 到 160MHz Cortex-M33。

无线 MCU 是全新的双核 STM32 微控制器系列，专为无线连接设计。它们覆盖 Sub-GHz 以及 2.4GHz 频率范围操作。它们易于使用、可靠，并完美适用于广泛的工业和消费应用。这些
