#### 21.5.1.2 Using CubeMX to Configure Flash Memory Interface

CubeMX simplifies the configuration of the bus used to access flash memory (TCM/AXI), of the ARTTM Accelerator and Cortex-M7 L1-cache. Going into Pinout view section and then clicking on the Cortex-M7 entry, it is possible to configure these parameters, as shown in Figure 21.7.
