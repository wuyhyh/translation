## This means that:

## - Only one PxY pin can be a source of interrupt. For example, we cannot define both PA0 and PB0 as input interrupt pins.
- For EXTI lines sharing the same IRQ inside the NVIC controller, we have to code the corresponding ISR so that we must be able to discriminate which lines generated the interrupt.

## The following example⁴ shows how to use interrupts to toggle the LD2 LED every time we press the user-programmable button, which is connected to the PC13 pin. First, we configure the GPIO PC13 to fire an interrupt every time it goes from the low level to the high one (line 79:82). This is accomplished by setting GPIO .Mode to GPIO_MODE_IT_RISING (for the complete list of available interrupt related modes, refer to Table 6.2). Next, we enable the interrupt of the EXTI line associated with the Px13 pins, that is EXTI15_10_IRQn.
