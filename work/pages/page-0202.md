## the priority mechanism is implemented in Cortex-M processors (that is, an exception with a given priority cannot be preempted by another one with same priority), exceptions and interrupts are not re-entrant. So, they cannot be called recursively¹⁷.

## However, in most of cases our code can be rearranged to address this limitation. In the following example the blinking code is executed inside the main() function, leaving to the ISR only the responsibility to setup the global blink variable.
