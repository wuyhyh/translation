## Now it is the right time to see a practical example. We are going to rearrange the Example 2 of this chapter so that we sample the switching frequency of PA5 pin (the one connected to LD2 LED) through the Channel 1 of TIM3 timer (in an STM32F072 MCU this pin coincides with PA6 pin). We so configure the Channel 1 as input capture pin, and we configure it in DMA mode so that it triggers the TIM_DMA_ID_CC1 request to automatically fill a temporary buffer that stores the value of the TIM3_CNT register when the rising edge of input signal is detected.
