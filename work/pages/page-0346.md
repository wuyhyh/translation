## Lines [45:49] configure the first channel of timer TIM2 to work in PWM Mode 1. The duty cycle will be range from 0 up to 999, which corresponds to the Period value. This means that we can regulate the output voltage with steps of ∼0,0033V if the output is well filtered (and the PCB has a good layout). This is close to the performances of a 10bit DAC.
