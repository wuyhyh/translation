```text
HAL_StatusTypeDef HAL_I2C_Mem_Write(I2C_HandleTypeDef *hi2c, uint16_t DevAddress,
uint16_t MemAddress, uint16_t MemAddSize,
uint8_t *pData, uint16_t Size, uint32_t Timeout);
HAL_StatusTypeDef HAL_I2C_Mem_Read(I2C_HandleTypeDef *hi2c, uint16_t DevAddress,
uint16_t MemAddress, uint16_t MemAddSize,
uint8_t *pData, uint16_t Size, uint32_t Timeout);
```

## allow to store and retrieve data from memory-addressable I²C devices, with just one notably difference: the HAL_I2C_Mem_Write() function is not designed to wait for the write-cycle completion, as we have done in the previous example at line 107. But, even for this operation the HAL provides a dedicated and more portable routine:

```text
HAL_StatusTypeDef HAL_I2C_IsDeviceReady(I2C_HandleTypeDef *hi2c, uint16_t DevAddress,
uint32_t Trials, uint32_t Timeout);
```

## This function accepts a maximum number of Trials before returning back an error condition, but if we pass to the function the HAL_MAX_DELAY as Timeout value, then we can pass 1 to the Trials argument. When the polled I²C device is ready the function returns HAL_OK. Otherwise, it returns the HAL_BUSY value.
