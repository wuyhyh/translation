## 20.2 The Really Minimal STM32 Application

The majority of applications seen until now seem really simple. Instead, both from the memory organization point of view and from the operations performed when the MCU boots, they already execute a lot of operations under the hood. For this reason, we are going to build a really essential application.

The first step is creating an empty project using STM32CubeIDE. Go to File->New->C/C++ Project menu. In the next dialog choose the C Managed Build type and click on Next. In the next dialog select the Executable->Empty Project in the Project type tree-view and MCU ARM GCC in the Toolchains section, as shown in Figure 20.3. Chose a Project name and click on Next. Skip the next wizard step and go to the Select default target for the project. Select the MCU for your development board by clicking on the Select button and click on Finish.
