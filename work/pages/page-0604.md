## Now it is the right time to analyze the three commands supported by this bootloader: CMD_GETID, CMD_ERASE and CMD_WRITE.

## Get ID Command The CMD_GETID command is used to retrieve the MCU ID¹⁷ and it has the structure shown in Figure 22.5. The bootloader so expects to retrieve the byte 0x02 followed by the CRC-32 of this byte. The bootloader answers to the request by sending an ACK (which is defined at line 8 of the mainbootloader.c file and it is equal to 0x79) followed by two bytes containing the MCU ID.

¹⁷The MCU ID is different from the CPU ID. The former identifies the STM32 family and chip type (for example, 0x433 identifies the STM32F401RE MCU).
