HEX binary format, a specification for binary files developed by Intel several years ago and still widespread especially in low-cost embedded platforms. The source code of this script is not shown here, but it should be easy to understand the way it is made. This script requires three additional modules: pyserial, IntelHex and pycryptodome libraries¹⁹.

You can easily install them using the pip command:

```text
$ sudo pip install intelhex pycryptodome pyserial
```

The script is designed to accept two arguments at command line:

- The serial port corresponding to the Nucleo VCP

- – In Windows this is equal to “COMx” string, where ‘x’ must be replaced with the COM number corresponding to Nucleo VCP (e.g. COM3). – In Linux and Mac OS this corresponds to a file mapped in the /dev path (usually something similar to /dev/tty.usbmodemXXXX).
- The complete path to the HEX file corresponding to the main firmware.
