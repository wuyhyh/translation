## It is possible to pass to the osThreadNew() the value NULL for the attr parameter: in this case the thread will be created with the default stack size specified by the macro configMINIMAL_STACK_SIZE inside the Core/Inc/FreeRTOSConfig.h file. Now it is the right time to see a practical example.
