If the global macro _USE_SDCARD_ is set and we are not using the ARM semihosting (so the global macro OS_USE_SEMIHOSTING is not set), then this means that web resources (HTML files, images and CSS/JS script files) are stored on a MicroSD card inserted in the W5500 shield card holder. The FatFs library is so initialized (lines [150:151]) and the first partition is mounted (line 153). Moreover, if we are using a debugger able to read ITM stimuluses, we print on the SWV console the content of the SD card by calling the scan_files() routine (which has been shown in Chapter 25).
