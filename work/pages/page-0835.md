#### 27.2.4.1 USB CDC Descriptors

Before going into details of CDC descriptors, it is best to do a quick recap. In the previous paragraph we have seen that, during the enumeration phase, the Host starts asking to the device for its configuration descriptors right after the SET_ADDRESS operation. Each configuration defines a set of interfaces, each one corresponding to a given class feature. To foster the compatibility among different devices implementing the same USB class, every interface in each USB class standardizes the number of communication endpoints and their communication behavior (interrupt, bulk, control, isochronous).
