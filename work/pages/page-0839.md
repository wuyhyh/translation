#### 27.2.4.2 USB CDC Class Initialization

## Again, before going into additional details, let us do a quick recap.

## 1. The device is connected to the host. After detecting the USB device speed mode (HS/FS), the host performs a SET_ADDRESS command by assigning a USB unique address on the bus. 2. The host then asks to the device for its Device Descriptors by issuing one or more GET_- DESCRIPTOR commands. 3. The host asks in this stage - or in a later one - for string descriptors by issuing several GET_- DESCRIPTOR commands. 4. The host next asks for device’s Configuration Descriptors by issuing one or more GET_DE- SCRIPTOR commands. The device will provide the configuration descriptors and all Interface Descriptors implemented.
