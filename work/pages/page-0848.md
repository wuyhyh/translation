#### 27.3.1.1 USB HID Descriptors

Every USB HID device shall provide the descriptors shown in Figure 19. Let us describe them.

![Image from PDF page 848](../images/page-0848-image-01.jpeg)

Figure 20: Descriptors hierarchy in a USB HID device

- Interface Descriptor: the HID class defines just one interface descriptor to announce to the host the device implements the HID protocol. The fields bInterfaceSubClass can assume the values 0=noboot and 1=boot: the value 1 indicates that the device adheres to the BOOT protocol. Because the parser for the Report Descriptor (shown next) represents a significant amount of code, a simpler method is needed to identify the device protocol for devices requiring BIOS support (BOOT devices). HID class devices use the bInterfaceSubClass field to indicate devices that support a predefined protocol
