Figure 21: Structure of the Custom HID generated project

- Class/CustomHID/Src/usbd_customhid.c: this file contains the complete implementation of the HID class protocol.

- – The array USBD_CUSTOM_HID_CfgFSDesc contains the full implementation of the HID descriptors (Configuration, Interface, HID and Endpoint descriptors). – The function USBD_CUSTOM_HID_Init() is responsible of the IN and OUT endpoints initialization. – The function USBD_CUSTOM_HID_Setup() contains the full implementation of the Class- specific Requests list in Table 20. – The function USBD_CUSTOM_HID_SendReport allows to send a report (a message) with a given LEN through the IN endpoint.
- USB_DEVICE/App/usbd_custom_hid_if.c: this file contains the actual implementation of the custom HID protocol.

– The array CUSTOM_HID_ReportDesc_FS contains the report descriptor, which will be passed to the host when the GET_DESCRIPTOR request is issued over the EP0. – The function CUSTOM_HID_OutEvent_FS() is a callback invoked once a report is sent by the host through the OUT endpoint.
