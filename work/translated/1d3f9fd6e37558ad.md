### - .glue_7 和 .glue_7t：这两个部分由 GCC 自动生成，它们引用

<!-- page: 547 -->

- 所谓的 ARM interwork 代码。这段“晦涩”的代码是一个前导部分（称为“glue”），在 ARM BX 或 BLX 汇编指令之后立即调用，这些指令用于在 ARM 模式和 Thumb/Thumb-2 模式之间切换 Cortex-M 内核。如第 1 章所述，Cortex-M 内核允许在运行时在 ARM 指令集和更优化（就大小而言）的 Thumb 指令集之间进行切换。两种模式之间的切换需要额外的操作，这些操作由编译器自动添加到二进制文件中。默认情况下，在常规的 STM32CubeIDE 应用程序中，不使用指令模式切换，并且由于默认设置了 --gc-sections 选项（参见图 20.4），链接器将丢弃这些部分。
- .eh_frame：此部分与 C++ 中抛出异常后执行堆栈展开操作时进行的操作有关。如果您的应用程序中不使用任何 C++ 代码，且设置了 --gc-sections 选项，则该部分将被静默丢弃。
- .init 和 .fini：这些部分将包含由 C 运行时库添加的初始化和去初始化代码。这些部分确保 C 运行时库的正确初始化，除非在项目设置中设置了 -nodefaultlibs 和 -nostdlib 选项（图 20.4），从而不使用任何 C 标准库函数。
