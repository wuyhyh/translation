第 24 章向读者介绍了一些高级调试技术。本章首先解释了基于 Cortex-M 内核中故障相关异常的作用，以及如何解读相关的硬件寄存器以追溯故障根源。此外，本章还介绍了 STM32CubeIDE 的所有高级调试工具，例如观察点（watchpoints）、表达式以及与 SWV 相关的工具。最后，简要介绍了 SEGGER J-LINK 专业调试器，以及如何在 Eclipse 工具链中使用它们。

第 25 章简要向读者介绍了 FatFs 中间件。该库允许操作使用广泛流行的 FAT12/16/32 文件系统创建的结构化文件系统。本章还展示了 ST 工程师如何将此库集成到 CubeHAL 中。最后，它概述了最相关的 FatFs 例程和配置选项。

第 26 章描述了一种使用 W5500 网络处理器将 Nucleo 开发板连接到互联网的方案。本章展示了如何使用 STM32 微控制器开发基于互联网和 Web 的应用程序，即使它们不提供原生以太网外设。此外，本章还向读者介绍了在静态网页中处理动态内容的可能策略。最后，展示了一个 FatFs 中间件的应用，以便在外部 SD 卡上存储网页等内容。

第 27 章介绍了一种广泛使用的通信协议：USB 2.0。本章将引导读者了解 USB 规范的基础知识，既从硬件角度，也从通信协议角度。此外，深入解释了 STM32 USB 设备栈，并提供了关于 USB-CDC 和 USB-HID 类的实用示例。

第 28 章展示了如何使用 STM32 MCU 开始新的自定义 PCB 设计。本章主要关注硬件相关方面，例如去耦、信号布线技术等。此外，它展示了如何在 PCB 设计过程中使用 CubeMX，以及当板级设计完成时如何生成应用程序骨架。

## 与第一版的区别

每一个后续版本都不是对前一个版本的完全重构。技术书籍也是如此。第二版与第一版有一些主要区别：

- 它已更新以反映 STM32 产品组合的最新演变。
- 它已完全更改以涵盖 STM32CubeIDE 工具链，该工具链与第一版中展示的不同（尽管两者都基于 Eclipse 和 GCC）。
- 它修复了几个错误（有些非常严重）。
- 它引入了第一版中不可用的全新主题。

## 关于作者

当有人问起我的职业生涯和学习经历时，我喜欢说，我是一名高级程序员，某天开始与比特（bits）搏斗。

我刚开始从事信息学工作时，还只是个拥有 80286 PC 的少年。但与那些从 BASIC 开始编程的人不同，我决定学习一种相当不常见的语言：Clipper。Clipper 主要用于编写银行软件，很多人建议我从这种编程语言开始（呃？！）。当像 Windows 3.1 这样的可视化环境开始变得更加普遍时，我决定学习 Visual Basic 的基础知识，并用它编写了几个程序（其中一个用于医生患者管理的程序进入了市场），直到我开始上大学，在那里我开始在 Unix 环境中使用 C/C++ 等编程语言进行编程。有一天，我发现了将成为我一生编程语言的 Python。我用 Python 编写了数十万行代码，范围从 Web 系统到嵌入式设备。我认为 Python 是一种富有表现力且高效的编程语言，每当我需要编写代码时，它总是我的首选。

大约八年间，我在意大利国家研究委员会（CNR）担任研究助理，在那里我花时间编写基于 Web 和分布式的内容管理系统。2010 年，我的职业生涯发生了巨大变化。由于一些我在这里不详细列出的原因，我一下子进入了一个我一直认为晦涩的世界：电子学。我最初开始在低成本 MCU 上开发固件，然后设计自定义 PCB。2010 年，我共同创立了一家生产用于小规模自动化的无线传感器和控制板的公司。不幸的是，这家公司运气不佳，未能达到我们想要的成功。

2013 年，我在 ST 位于那不勒斯的总部的一次展示日上接触到了 STM32 世界。自那以后，我在设计的多个产品中成功使用了 STM32 微控制器，范围从工业自动化到安全令牌。甚至得益于这本书的成功，我目前主要作为全职硬件顾问为一些意大利公司工作。

2016 年，我加入了 Bit4id，一家全球领先的 PKI 系统公司。我最初作为硬件顾问帮助开发蓝牙智能卡读卡器，几年后最终成为公司最重要业务部门的负责人，管理着约 1200 万欧元的总业务、数千名客户、30 多名杰出的工程师、销售人员以及每年约 200 万台设备的完整生产。为了支持向更管理角色的转变，我在一所欧盟商学院参加了 MBA 课程。我喜欢这种新的管理角色生活吗？下一个问题？？！?! :-D

2021 年，我的第一个女儿出现在我的生活中。好吧，自那以后事情发生了很大变化，正如您可以想象的那样。我的空闲时间大大减少，这也是这本书第二版真正迟到的原因之一 ;-)
